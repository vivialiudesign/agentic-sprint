# Release notes

## v2.0.0 — Live HTML sprint workspace

Agentic Sprint’s second release makes the Sprint Review page the default working surface.

### Added

- Create and share the live HTML review link before Phase 1 begins.
- Reflect meaningful human input, research, agent insights, concepts, votes, decisions, prototypes, and recommendations as they happen.
- Keep artifacts in chronological phase order with universal navigation and a visible active phase.
- Keep Diverge Round 1 before Round 2, with each round’s concepts and votes together.
- Distinguish human input, agent proposals, and facilitator synthesis visually.
- Use stable agent avatars or role badges and the human’s supplied avatar when available.
- Embed competitive evidence, sketches, and prototypes with source links.
- Preserve the confirmed visual language and document how supplied references shape it.
- Run responsive visual QA before each handoff.
